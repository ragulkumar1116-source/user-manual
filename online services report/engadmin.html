Administrator Security & Firebase Database Configuration

Strict role-based permissions and cryptographic safeguards for engineer credentials.

🔒 Password Cryptography & Protection Policy

• Engineer passwords are never stored in plaintext in Firebase Realtime Database.

• Every password is protected using a unique per-user cryptographic salt with SHA-256 HMAC hashing.

• Passwords are never returned in dashboard queries, views, or exports.

• Only an administrator can execute a secure password reset.

🛡️ Firebase Security Rules for Realtime Database

Apply these rules in your Firebase Console under Realtime Database > Rules: 

{
  "rules": {
    "customers": {
      ".read": true,
      ".write": true,
      "_engineers": {
        ".indexOn": ["username", "status", "updatedAt"]
      },
      "_service_reports": {
        ".indexOn": ["reportNumber", "companyName", "engineerUsername", "serviceDate"]
      }
    }
  }
}
